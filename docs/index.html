Canon R7 EXR Converter

Converts Canon Log 3 clips from the Canon EOS R7 into scene-linear ACEScg EXR sequences for Nuke, with optional ProRes for review.

Download the latest version

Windows 10/11, 64-bit. Get the Setup.exe: it installs without admin rights and updates itself. The zip also works, but you update it by hand.

Documentation

  • Manual Converting clips, the Advanced tab, and setting up Nuke (OCIO, ACES 1.3).
  • Headless mode Command-line reference for batch jobs and pipeline scripts.
  • What's new Release notes for every version.

Quick start

  1. Install and open the converter.
  2. Click Add clips… and pick your R7 .MP4 files.
  3. Choose where to save, then click Convert.
  4. In Nuke, set the colour management to OCIO with an ACES 1.3 config, and read the EXRs as ACEScg.

The app's Help menu opens this page and checks for updates.
